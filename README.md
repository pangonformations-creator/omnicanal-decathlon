# TD Decathlon — Seconde vie sportive

Support pédagogique comprenant une page d’accueil, trois parties de questions ouvertes et des ressources téléchargeables.

## Publication sur GitHub Pages

1. Placer index.html, images/, resources/ et .nojekyll à la racine du dépôt.
2. Dans Settings > Pages, choisir Deploy from a branch.
3. Sélectionner main puis / (root), et enregistrer.

Aucune compilation ni installation nécessaire. Les liens vers les images et le fichier Excel sont relatifs et compatibles avec un site GitHub Pages de projet.

## Contenu

- Accueil : problématique et travail attendu.
- Parties I à III : questions et illustrations.
- Ressources : visuels du TD et exemple Excel Steak veggie.

## Modification

Les textes, styles et la navigation sont dans index.html. Les illustrations sont dans images/ et le fichier Excel dans resources/.
